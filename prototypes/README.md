# Prototypes

This directory holds runnable experiments and local testbeds that exercise the
workspace packages without expanding the core package surface.

- `rust/video-analysis-use-cases`: end-to-end workflow and use-case prototype.
- `web/video-analysis-web`: local web prototype for workflows, reports, and
  architecture exploration.

Future experimental apps such as search engines, recommendation engines, and
workflow sandboxes should live here rather than under `crates/` or `packages/`.
