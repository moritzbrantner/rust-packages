# text-analysis-search

Unified search API for large text corpora in `video-analysis`.

## Highlights

- Full-text, semantic, and hybrid search modes
- Metadata and tag filters
- Relevance, id, and metadata sorting
- Facet counts over candidate results
- Reusable ingestion through `text-analysis-retrieval`
