# Agent Issue Tracker

## Tracker

This repository uses GitHub Issues as the agent workflow tracker.

- Repository: `moritzbrantner/rust-packages`
- Tracker URL: `https://github.com/moritzbrantner/rust-packages/issues`

Issues are the source of truth for triage, PRDs, work that is ready for an AFK
agent, blocking state, and completion state. Agents should not use local
markdown files as the issue tracker for this repository.

Use the labels documented in [triage-labels.md](triage-labels.md) to move work
through the workflow.
