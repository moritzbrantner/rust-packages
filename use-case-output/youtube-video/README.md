# YouTube Video Use-Case Output

This directory keeps small reviewed report snapshots only. Large media files such as
`youtube-video.mp4` and `audio.wav` are generated local artifacts and are not
checked in.

Recreate local media outputs by running the YouTube video use-case workflow from
`prototypes/rust/video-analysis-use-cases`. Keep generated media under
`use-case-output/`; `.gitignore` prevents common audio/video outputs from being
committed.
