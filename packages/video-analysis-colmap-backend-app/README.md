# video-analysis-colmap-backend-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-colmap-backend`.

Run the server:

```bash
cargo run -p video-analysis-colmap-backend-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-colmap-backend-app dev
```
