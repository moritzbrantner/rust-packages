# video-analysis-gaussian-splatting-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-gaussian-splatting`.

Run the server:

```bash
cargo run -p video-analysis-gaussian-splatting-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-gaussian-splatting-app dev
```
