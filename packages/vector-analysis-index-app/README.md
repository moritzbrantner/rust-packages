# vector-analysis-index-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `vector-analysis-index-server`.

Run the server first:

```bash
cargo run -p vector-analysis-index-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/vector-analysis-index-app dev
```
