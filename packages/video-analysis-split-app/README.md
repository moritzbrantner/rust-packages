# video-analysis-split-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-split-server`.

Run the server first:

```bash
cargo run -p video-analysis-split-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/video-analysis-split-app dev
```
