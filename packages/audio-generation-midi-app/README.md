# audio-generation-midi-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `audio-generation-midi-server`.

Run the server first:

```bash
cargo run -p audio-generation-midi-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/audio-generation-midi-app dev
```
