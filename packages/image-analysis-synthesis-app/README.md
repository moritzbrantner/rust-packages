# image-analysis-synthesis-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `image-analysis-synthesis-server`.

Run the server first:

```bash
cargo run -p image-analysis-synthesis-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/image-analysis-synthesis-app dev
```
