# video-analysis-test-support-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-test-support`.

Run the server:

```bash
cargo run -p video-analysis-test-support-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-test-support-app dev
```
