# video-analysis-radiance-fields-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-radiance-fields-server`.

Run the server first:

```bash
cargo run -p video-analysis-radiance-fields-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/video-analysis-radiance-fields-app dev
```
