# three-d-processing-io-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `three-d-processing-io-server`.

Run the server first:

```bash
cargo run -p three-d-processing-io-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/three-d-processing-io-app dev
```
