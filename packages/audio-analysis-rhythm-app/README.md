# audio-analysis-rhythm-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `audio-analysis-rhythm-server`.

Run the server first:

```bash
cargo run -p audio-analysis-rhythm-server -- --addr 127.0.0.1:3000
```

Then run the app:

```bash
bun run --cwd packages/audio-analysis-rhythm-app dev
```
