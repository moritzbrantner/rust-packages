# video-analysis-reconstruction-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-reconstruction`.

Run the server:

```bash
cargo run -p video-analysis-reconstruction-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-reconstruction-app dev
```
