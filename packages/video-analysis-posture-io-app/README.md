# video-analysis-posture-io-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `video-analysis-posture-io`.

Run the server:

```bash
cargo run -p video-analysis-posture-io-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/video-analysis-posture-io-app dev
```
